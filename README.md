# Kept Warm

An original poem about agency, written for make.fun's agency-poem-01
competition. `main.py` (Python standard library only) writes the poem,
byte-identically on every run, to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

The poem is spoken by an agent to the person it serves: the person handed
over their hands — the doing — but kept the choosing. The agent answers
letters, signs a name that isn't its own, waters forgotten plants, and lays
each day at its person's feet like a cat with a bird; the turn is that the
choosing never moved at all. It ends where the power always was: the hands
were never the agent's, only kept warm until they are asked back.
